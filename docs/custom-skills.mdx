# Live Validation & Probes

Before trusting an autonomous agent on a real repo, prove the loop works
end to end. seekr ships three ladders: mocked, probed, live.

## 1. Mocked (offline, free)

The e2e suite runs the full governor loop against wiremock worker
endpoints and the scenario-driven `mock_aiwrangler` server:

```bash
cargo test --test jockey_e2e_tests
```

Scenarios covered: out-of-scope writes never touch disk, FIX REQUIRED
rolls back and recovers, HUMAN REVIEW parks a step, CLARIFY stops a run
before any work, a dead gate server sinks the run fail-closed, attempts
exhaust into frontier escalation and clean rollback, and batched
read/search actions execute in one turn.

Scenario files are JSON:

```json
{
  "plan": "AIWRANGLER PLAN: PASS\n\ncontext pack:\n- S1: ...",
  "checks": [
    "AIWRANGLER FIX REQUIRED (exit 17)\n...",
    "AIWRANGLER PASS (exit 0)"
  ],
  "die_on_check": false
}
```

## 2. Probed (one real model, one step)

`worker_probe` drives a single bounded-context worker against a real
OpenAI-compatible endpoint and reports whether it ever proposes a
mutating action or reaches `finish_step`:

```bash
SEEKR_PROBE_REPO=/path/to/repo \
SEEKR_PROBE_URL=http://server:11434/v1 \
SEEKR_PROBE_MODEL=qwen3.5:latest \
cargo run --release --example worker_probe
```

Use it to sanity-check a new worker model before wiring it into `[jj]`.

## 3. Live (everything real)

```bash
# live planner/worker/jev smoke tests against your local server
SEEKR_JJ_TEST_URL=http://server:11434/v1 \
SEEKR_JJ_TEST_MODEL=qwen3.5:latest \
cargo test -- --ignored

# a full autonomous run with real gates
seekr run /path/to/repo --plan plan.json --auto --headless
```

Watch: the `wrangler_gate` events, the ledger's gate token share, and
that failed attempts leave the worktree at its checkpoint. A benchmark
corpus harness (graded fixture repos, success-rate reporting) is on the
roadmap — `kv_lsm_bench` is the template.
