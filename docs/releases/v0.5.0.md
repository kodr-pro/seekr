# Release Notes — v0.5.0: Governed by AiWrangler 🛡️

seekr's semantic governance now runs on
[AiWrangler](https://github.com/kodr-pro/AiWrangler), the released
ground-truth guardrail product — instead of the scavenged copy of that
logic that shipped inside 0.4.0. One `aiwrangler-mcp` subprocess per
run, the same gates your other coding agents use, the same audit
ledger.

## What changed

- **Plan gate**: goal + DAG are judged against your ground truth before
  any code is written. CLARIFY and HUMAN verdicts stop the run before a
  single byte lands; on PASS, the context pack (spec sections, rulings,
  open questions) becomes required reading in every worker prompt.
- **Step check gate**: every completed step now passes AiWrangler's
  battery — scope discipline, claims-vs-diff, silent defaults, prompt
  injection, test quality — over the dirty worktree plus the worker's
  own summary. FIX REQUIRED feeds cited findings straight back into the
  next attempt.
- **Human in the loop**: HUMAN REVIEW parks a step until the owner runs
  `seekr ack <run-id>`. Acknowledgments are audited and diff-bound.
- **Leaner interceptor**: per-action judgment moved to the step gate,
  where the whole diff is visible; the deterministic guards (path
  sandbox, blocklist, duplicate fingerprints) remain, fail-closed.
- **Your corpus governs**: repos that commit an `aiwrangler.config.json`
  get their own spec/rules/rulings enforced in every run; others get a
  generated minimal gate config so the gates are always on.

## Also new

- `bench/` — a graded fixture corpus (LRU, CSV, token bucket, base32,
  WAL) and a runner that reports step/DAG completion, gate verdicts, and
  token tiers against the release bar.
- `mock_aiwrangler` — a scenario-driven stand-in MCP server; the full
  governor loop is now testable offline, and installs can be smoke-tested
  without spending judgment tokens.
- Worker anti-stall: no todo fixation, cached re-reads are free, no-op
  turns abort, and the action cap auto-verifies real work.
- Old run states still load (`jev_*` ledger fields map to `wrangler_*`).

## Upgrade

```bash
cargo install --path .
# install AiWrangler (Node 20+)
git clone https://github.com/kodr-pro/AiWrangler && cd AiWrangler \
  && npm install && npm run build && npm link
seekr doctor   # verifies providers, roles, and the gate server
```

`[jj]` config: `scope_threshold` and `novelty_reject_at_or_below` are
gone — policy lives in AiWrangler's config now. Add
`wrangler_command` if the server isn't on PATH as `aiwrangler-mcp`.
