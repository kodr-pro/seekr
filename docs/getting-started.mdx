# Installation

Getting **seekr** running takes three things: the binary, an
OpenAI-compatible model endpoint, and
[AiWrangler](https://github.com/kodr-pro/AiWrangler) for the gate
lifecycle.

## Prerequisites

- **Rust** (to install from source):
  ```bash
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  ```
- **git** — runs live in linked worktrees.
- **Node 20+** with AiWrangler built:
  ```bash
  git clone https://github.com/kodr-pro/AiWrangler.git
  cd AiWrangler && npm install && npm run build && npm link
  ```
- **A local model endpoint** — any OpenAI-compatible server (Ollama,
  vLLM, llama.cpp server). A small coder model works well; seekr was
  tuned against `qwen3.5`.
- **A frontier model key** — for Phase 0 planning and escalations (any
  OpenAI/Anthropic/Gemini-compatible provider).
- **`TYPESAFE_API_KEY`** — powers AiWrangler's semantic battery. Without
  it, completed steps come back DEGRADED and runs fail closed.

## Install seekr

```bash
cargo install --path .
seekr doctor
```

`doctor` verifies providers, worker/frontier roles, and does a live
spawn + config round-trip against the AiWrangler server.

## Configure

`~/.config/seekr/config.toml`:

```toml
[[providers]]
name = "qwen-local"
base_url = "http://server:11434/v1"
model = "qwen3.5:latest"

[[providers]]
name = "glm-frontier"
key = "..."                  # or GLM_FRONTIER_API_KEY env
base_url = "https://api.z.ai/api/coding/paas/v4"
model = "glm-5.3"

[jj]
worker_provider = "qwen-local"
frontier_provider = "glm-frontier"
# optional; default is "aiwrangler-mcp" resolved from PATH
wrangler_command = "node /path/to/AiWrangler/dist/mcp.js"
```

For Ollama thinking models, export
`SEEKR_WORKER_REASONING=none` — 2s/turn instead of 70s.

## First run

```bash
seekr .                                # TUI: goal → clarify → plan review → dashboard
seekr run . --goal "add a bounded LRU cache in src/lru.rs with tests"
seekr run . --goal "..." --headless --json | jq -c 'select(.type=="step_completed")'
```

Watch the run land on a `jj/<run-id>` branch in a worktree under
`<repo>/../.jj-worktrees/`. Inspect, then:

```bash
seekr merge <run-id>     # merge the branch back and clean the worktree
```

If AiWrangler returns HUMAN REVIEW on a step, the run parks:

```bash
seekr ack <run-id>                          # see the findings
seekr ack <run-id> --rules RULE-10 --note "reviewed: intentional"
seekr resume <run-id>
```
