# Introduction

**OpenCode when you're driving. Seekr when you're sleeping.**

Seekr is an autonomous coding agent for long, well-specified tasks. You
queue the work, walk away, and come back to finished branches with a
reviewable paper trail — at a fraction of the cost of running a frontier
model end to end.

## The bet

| Tier | Cost | Quality |
|---|---|---|
| Frontier API models | expensive per token | accurate, plans well |
| Local models | free, runs all night | drift on long tasks |
| [AiWrangler](https://github.com/kodr-pro/AiWrangler) | cheap judgments | calibrated, citable |

Big-model agents cost dollars per task. Local-model agents drift within
the hour. Seekr combines all three: **the frontier writes the plan and
occasionally finishes a stuck step; the local model does the
overwhelming majority of the work; AiWrangler gates every completed step
against the documents that actually govern your repo.** The only real
cost is server horsepower — and when the local tier carries the task,
the run's ledger shows zero frontier calls.

## The loop

1. **Plan** — frontier decomposes the goal into a rigid DAG (invariants,
   allowed paths, verification commands). The plan gate judges it
   against your ground truth before anything touches disk: ambiguity
   stops for answers, one-way doors stop for the owner.
2. **Grind** — the local worker acts one small step at a time under a
   fail-closed interceptor, with inline compile feedback and kept-diff
   retries.
3. **Gate** — each completed step passes its verification command, then
   the check battery: scope discipline, claims-vs-diff, silent
   defaults, injection defense, test quality.
4. **Finish** — two stalled attempts and the frontier steps in:
   guidance first, a verified patch if that fails.
5. **Review** — a severity-first summary of what needs you, findings
   that become review notes on merge.

## What it's for

**Shines:** test backfill, dependency migrations, lint debt, doc drift,
mechanical refactors — verification-friendly work where "done" is a
command that exits 0.

**Not for:** novel features without a test suite, exploratory spikes.
No deterministic verification, no anchor for the gates — use your
interactive agent for those.
