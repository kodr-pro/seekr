# Introduction

**seekr** is an autonomous, cost-guarded coding agent. You give it a
goal; a frontier model plans a rigid task DAG; a cheap local model
grinds through every step; [AiWrangler](https://github.com/kodr-pro/AiWrangler)
gates the plan and every completed step against your ground truth;
deterministic verification runs between attempts; and git worktrees make
every run reversible.

## Why it exists

Letting a small local model loose on a repo unsupervised is cheap — and
terrifying. seekr's whole architecture is about making that safe:

- **The plan is rigid.** The frontier model decomposes the goal into a
  validated DAG with per-step invariants, allowed paths, and a
  deterministic verification command. The worker cannot wander.
- **Every action is intercepted.** Path sandboxing, a shell blocklist,
  and a duplicate-fingerprint loop breaker reject unsafe or stuck
  actions deterministically — fail-closed, no network required.
- **Every completed step is gated.** AiWrangler's check battery reads
  the dirty diff, the worker's own summary, and the verification output,
  and catches claims that outrun the diff, scope creep, silent defaults,
  injected steering text, and missing tests. Anything touching a one-way
  door stops for a human.
- **Everything is reversible.** Each verified step checkpoints; each
  failed attempt rolls back to it — including untracked files. Your main
  checkout is never touched; runs live on `jj/<run-id>` branches in
  linked worktrees.

## The loop at a glance

1. **Plan** — frontier decomposes the goal (bounded clarification
   rounds), then AiWrangler's plan gate returns PASS / CLARIFY / HUMAN
   plus a ground-truth context pack the worker must honor.
2. **Grind** — the worker proposes one small action at a time against a
   fresh, bounded context; the interceptor checks it deterministically.
3. **Verify + gate** — `finish_step` triggers the step's verification
   command, then the AiWrangler check gate over the dirty worktree.
   PASS checkpoints, FIX REQUIRED feeds cited findings back, HUMAN
   REVIEW parks the step for `seekr ack`.
4. **Triage / escalate** — deterministic triage decides whether to
   retry, inject context, or escalate to the frontier (hard budget).
